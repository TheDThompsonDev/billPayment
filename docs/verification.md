## Failures found and repaired

1. Prisma's Windows SQLite initialization returned an uninformative schema-engine error when the database did not exist. The setup script now creates an empty file before schema synchronization; clean setup and reset passed.
2. The first browser upload was rejected because Next normalized the internal URL to localhost while the browser used 127.0.0.1. The origin check now compares the actual Host header and allows only loopback origins. Valid browser mutations pass; a different origin is rejected.
3. A screen-reader table label escaped its scroll container on mobile. The container now establishes a positioning context. Browser measurements confirm no page overflow.
4. Initial browser tests had ambiguous text selectors shared by links/inputs or alert/timeline text. Tests now select by role and section without weakening their behavioral assertions.
5. Running two development servers produced excessive compilation churn. Browser tests now use the production build and their own database/port.
6. An inherited anchor color reduced contrast on the primary link-button. Its text is explicitly white; browser computed style confirmed `rgb(255, 255, 255)`.
7. Final review aligned audit dates and times to America/Chicago, made event ordering deterministic for timestamp ties, and showed schema success independently from matching success.
