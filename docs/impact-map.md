Design choices: modular monolith; integer cents; Prisma 6 SQLite engine; deterministic sample fixtures; payments are mock-only. Payment submission is idempotent and reconciles a pending mock payment after refresh.

Known limits to preserve: local demo persona switch is not production authentication; live AI requires a configured key and network and is not required for any sample; SQLite is a single-host demonstration database. Unknown documents without a key require manual confirmation. Optional investigation agent is out of scope.

Both were repaired and checked in the browser. Database initialization needed an explicit empty file on this Windows host; portable setup now does that before Prisma synchronization. Test servers use their own database and the production build to avoid altering the live demo or competing development watchers.

Final verification is recorded in `docs/verification.md`.
